# Fuel Consumption Analysis System

## Project Objective
To analyze vehicle fuel consumption, calculate mileage,
estimate fuel costs, and display useful information through graphs.

## Technologies Used
- Python
- Flask
- MySQL
- Pandas
- NumPy
- Matplotlib

## Main Features
- Calculate vehicle mileage.
- Calculate fuel expenses.
- Estimate fuel required for a journey.
- Store vehicle and fuel records in MySQL.
- Analyze fuel consumption data.
- Display graphs for better understanding.

## Project Files
- app.py - Main Flask application
- calculations.py - Fuel calculation functions
- test_calculations.py - Basic calculation tests
- README.md - Project documentation

## How to Run
1. Open the project in PyCharm.
2. Install the required Python libraries.
3. Start the Flask application by running app.py.
4. Open the local URL displayed in the terminal.

## Expected Result
The system helps users understand vehicle fuel
consumption, mileage, and fuel expenses.
